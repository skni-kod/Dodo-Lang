# dodoc

### The compiler nobody asked for!

## What is it?

This repository contains the source code for my own compiler, written for the Dodo Lang programming language. 

That language is entirely made up by me, borrowing syntax and functionalities from C++, Rust, Zig and others, combining the things I like the most about them into one!

## Any actual uses?

The language itself makes heavy use of templates, operator overloads, variable count arguments and compile time calculations. With some luck, this will lead to great performance when compiled into a program by Clang or any other backend I choose to adopt.

## Technologies

- Zig 0.16
- Flex
- GNU Bison
- Clang IR
