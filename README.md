# dodoc

### Kompilator, o który nikt nie pytał!

## Co to?

To repozytorium zawiera kod źródłowy mojego własnego kompilatora, napisanego dla języka programowania Dodo Lang.

Ten język jest całkowicie przeze mnie wymyślony, zapożycza składnię i funkcjonalności z C++, Rust, Zig i innych, łącząc rzeczy, które w nich najbardziej lubię w jedno!

## Jakiekolwiek zastosowania?

Sam język w dużym stopniu używa szablonów, przeładowań operatorów, argumentów o zmiennej ilości i kalkulacji w trakcie kompilacji. Z odrobiną szczęścia, da to świetną wydajność po skompilowaniu w program przez Clang albo jakiś inny backend, który postanowię przyjąć.

## Technologie

- Zig 0.16
- Flex
- GNU Bison
- Clang IR
